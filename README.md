# Dashboard de Gestion Presupuestal Logística 2026
Dashboard para el control de CAPEX y OPEX en proyectos de infraestructura y logística

Tecnologías y Metodología:
Modelado de datos: Estructuración y modelado de datos maestros de costos en Excel
DAX: Creación de medidas personalizadas para el cálculo de Variación presupuestal, % de Ejecucion y proyecciones de CAPEX
